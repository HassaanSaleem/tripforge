# User Test Card: seed-0014

## Feature (one sentence)
An agent drafting an AI itinerary sees the same finished, budget-fit trip as before — the draft form now streams progress under the hood, but produces the identical result.

## Prerequisites
- [ ] The live stack is running at http://localhost:3000 (the implementer booted it)
- [ ] A browser is available via the Playwright MCP tools

## Prerequisite Verification Commands
```bash
curl -sf http://localhost:3000/api/health   # should print a JSON body containing "ok"
```

## Steps

### Step 1: Create an agency account
**Browser action:** navigate to http://localhost:3000/sign-up, fill "Your name" with
"Uma UAT", fill "Email" with "uma-uat-seed0014@example.test", fill "Password" with
"uat-seed0014-pw", fill "Agency name" with "Umbrella UAT Travel", click
"Create account & agency"
**Expected visible result:** "Plan a trip" (the workspace planner) and "Umbrella UAT Travel"
in the header
**Expected NOT visible:** "Invalid" or any error banner
**Screenshot:** save as step-1.png in the evidence directory

### Step 2: Draft a trip and watch the button state while it works
**Browser action:** on http://localhost:3000/workspace, fill "Destination" with "Paris",
fill "Check-in" with "2026-09-01", fill "Check-out" with "2026-09-04", fill "Budget" with
"1000", fill "Currency" with "USD", click "Draft itinerary"
**Expected visible result:** immediately after clicking, a button reading "Drafting…" that
cannot be clicked again
**Expected NOT visible:** the "Draft itinerary" button staying clickable after you click it
**Screenshot:** save as step-2.png in the evidence directory

### Step 3: The finished itinerary appears
**Browser action:** wait up to 30 seconds for the draft to finish
**Expected visible result:** "Paris balanced trip", "Day 1", and "Budget summary"
**Expected NOT visible:** "Draft failed"; the "Drafting…" button still showing
**Screenshot:** save as step-3.png in the evidence directory

### Step 4: A hopeless budget is refused with one clear message
**Browser action:** navigate to http://localhost:3000/workspace, fill "Destination" with
"Reykjavik", fill "Check-in" with "2026-09-10", fill "Check-out" with "2026-09-13", fill
"Budget" with "1", fill "Currency" with "EUR", click "Draft itinerary", wait up to 30
seconds
**Expected visible result:** either "No bookable options fit this trip and budget. Try
adjusting the budget, dates, or destination." or "The planner could not produce a usable
plan this time. Please try again."
**Expected NOT visible:** a blank page; "Draft itinerary" form disappearing; any text
containing "Error:" or "TypeError"
**Screenshot:** save as step-4.png in the evidence directory

### Step 5: The failed form still has your values
**Browser action:** look at the "Destination" field on the same page
**Expected visible result:** "Reykjavik" still in the Destination field
**Expected NOT visible:** an empty Destination field
**Screenshot:** save as step-5.png in the evidence directory
