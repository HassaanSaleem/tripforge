# User Test Card: seed-0015

## Feature (one sentence)
Two agents booking the same trip's holds at the same moment both get a clean, typed answer — exactly one booking succeeds, the other is told the holds were already consumed, and the platform never returns a server error (500) or deadlocks.

## Prerequisites
- [ ] The TripForge stack is running and healthy at http://localhost:3000
- [ ] `docker` is available (the stack's own logs and database are inspected through it)
- [ ] `node` (v20+) is available

## Prerequisite Verification Commands
```bash
curl -s http://localhost:3000/api/health      # should print {"status":"ok","db":"up"}
docker compose ps --format '{{.Service}} {{.Status}}' | sort   # postgres/mailpit/web running or healthy, migrate exited
node --version                                 # should print v20 or higher
```

## Steps

### Step 1: The platform is up with a live database round-trip
```bash
curl -s -o /tmp/uat-seed-0015-health.json -w "%{http_code}" http://localhost:3000/api/health && cat /tmp/uat-seed-0015-health.json
```
**Expected exit code:** 0
**Expected output contains:** `200` and `"status":"ok"` and `"db":"up"`
**Expected output does NOT contain:** `"db":"down"`

### Step 2: Booking is refused gracefully for an anonymous caller (negative test)
```bash
curl -s -o /dev/null -w "%{http_code}\n" -X POST -H "content-type: application/json" -H "origin: http://localhost:3000" -d '{"itineraryId":"00000000-0000-0000-0000-000000000000","quoteRowIds":["00000000-0000-0000-0000-000000000000"]}' http://localhost:3000/api/trpc/workspace.booking.book
```
**Expected exit code:** 0
**Expected output contains:** `401`
**Expected output does NOT contain:** `500`

### Step 3: A full build-to-book walk where two book requests race the same holds answers typed — one winner, one graceful loser, no server error
```bash
BASE_URL=http://localhost:3000 node tests/integration/smoke.mjs
```
**Expected exit code:** 0
**Expected output contains:** `both concurrent book requests answer typed (200 — no deadlock 500)`
**Expected output contains:** `exactly one concurrent booking wins`
**Expected output contains:** `the losing racer fails typed — already_consumed on every component`
**Expected output contains:** `L3 smoke PASSED.`
**Expected output does NOT contain:** `FAIL`

### Step 4: The database logged no deadlock during the race
```bash
docker compose logs --no-color | grep -E "deadlock detected" | wc -l | tr -d ' '
```
**Expected exit code:** 0
**Expected output contains:** `0`
**Expected output does NOT contain:** `deadlock detected`
