# User Test Card: seed-0010

## Feature (one sentence)
A fresh checkout of the repo builds and boots the full TripForge stack with one
command — no host-installed dependencies needed.

## Prerequisites
- [ ] Docker daemon is running
- [ ] This checkout has NO installed workspace deps (that is the point of the test)

## Prerequisite Verification Commands
```bash
docker info --format '{{.ServerVersion}}'   # prints a version number
test ! -d node_modules && echo CLEAN        # prints CLEAN
```

## Steps

### Step 1: Build and boot the whole stack from this clean checkout
```bash
docker compose down -v --remove-orphans; docker compose up --build --wait
```
**Expected exit code:** 0
**Expected output contains:** "Healthy"
**Expected output does NOT contain:** "next: not found"

### Step 2: The running app passes the L3 smoke against real routes and a real DB
```bash
node tests/integration/smoke.mjs
```
**Expected exit code:** 0
**Expected output contains:** "L3 smoke PASSED."
**Expected output does NOT contain:** "FAIL"

### Step 3: Health endpoint round-trips the database
```bash
curl -s http://localhost:3000/api/health
```
**Expected exit code:** 0
**Expected output contains:** "\"db\":\"up\""
**Expected output does NOT contain:** "error"

### Step 4: Unknown routes are rejected gracefully (negative test)
```bash
curl -s -o /dev/null -w '%{http_code}' http://localhost:3000/does-not-exist
```
**Expected exit code:** 0
**Expected output contains:** "404"

### Step 5: Server logs contain no error-level lines
```bash
docker compose logs --no-color | grep -E "ERROR|FATAL|Unhandled" | wc -l
```
**Expected exit code:** 0
**Expected output contains (trimmed):** "0"

### Step 6: Tear down
```bash
docker compose down -v
```
**Expected exit code:** 0
**Expected output contains:** "Removed"
**Expected output does NOT contain:** "error"

## Constraints
- MAX_DURATION: 900
  (exception to the usual <300s guideline, documented here: Step 1 cold-compiles
  the Next.js app inside the image build — the docker build, not the assertions,
  dominates the wall clock)
