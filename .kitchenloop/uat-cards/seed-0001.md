# User Test Card: seed-0001

## Feature (one sentence)

The TripForge app serves an agent-facing **workspace** and a white-labeled
**client view**, prompts anonymous visitors to sign in before the workspace, and
exposes a health endpoint that reports a live database connection.

## Prerequisites

- [ ] The app is running and reachable at http://localhost:3000
- [ ] The server log is captured at /tmp/next-start.log

## Prerequisite Verification Commands

```bash
curl -s -o /dev/null -w "%{http_code}" http://localhost:3000/api/health   # should print 200
test -f /tmp/next-start.log && echo "log-present"                          # should print log-present
```

## Steps

### Step 1: Open the home page
**Browser action:** navigate to http://localhost:3000/
**Expected visible result:** the heading text "TripForge" and a link labelled "Agency workspace"
**Expected NOT visible:** "Application error" or "500"
**Screenshot:** save as step-1.png in the evidence directory

### Step 2: Open the agency workspace as an anonymous visitor
**Browser action:** navigate to http://localhost:3000/workspace
**Expected visible result:** the heading "Agency workspace" and text containing "agency membership" (the sign-in prompt shown because no agent is signed in)
**Expected NOT visible:** "Application error" or a stack trace
**Screenshot:** save as step-2.png in the evidence directory

### Step 3: Open the white-labeled client view
**Browser action:** navigate to http://localhost:3000/view
**Expected visible result:** the heading "Your trip" and text mentioning the agent's branded proposal
**Expected NOT visible:** "Application error"
**Screenshot:** save as step-3.png in the evidence directory

### Step 4: Health endpoint reports a live database
```bash
curl -s http://localhost:3000/api/health
```
**Expected exit code:** 0
**Expected output contains:** "\"db\":\"up\""
**Expected output does NOT contain:** "\"db\":\"down\""

### Step 5: Auth-gated workspace API rejects an unauthenticated caller (negative test)
```bash
curl -s -o /dev/null -w "%{http_code}" http://localhost:3000/api/trpc/workspace.whoami
```
**Expected exit code:** 0
**Expected output contains:** "401"
**Expected output does NOT contain:** "200"

### Step 6: Public health API is open to anyone
```bash
curl -s http://localhost:3000/api/trpc/health
```
**Expected exit code:** 0
**Expected output contains:** "\"status\":\"ok\""

### Step 7: Server log has no error-level lines
```bash
grep -E "ERROR|FATAL|Unhandled" /tmp/next-start.log || echo "LOG_CLEAN"
```
**Expected exit code:** 0
**Expected output contains:** "LOG_CLEAN"

## Artifacts

- step-1.png, step-2.png, step-3.png in the evidence directory (one per browser step)
- .kitchenloop/uat-runs/seed-0001/evidence.md containing raw output for every step

## Constraints

- MAX_DURATION: 180
