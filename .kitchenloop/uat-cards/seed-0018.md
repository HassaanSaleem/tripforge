# User Test Card: seed-0018

> This card verifies that licensed white-label copies are now visibly
> distinguishable from originals in the sell-form picker, the workspace trip
> list, and cross-tenant marketplace listing cards — the exact gap that
> caused a false PRODUCT_FAIL in a prior UAT run (seed-0016, PR #31), where
> the evaluator could not tell a licensed copy apart from an original in the
> picker because both showed only "title (currency)".

## Feature (one sentence)
After licensing a marketplace listing, the resulting copy is visibly marked as a licensed copy (naming the original author) everywhere it appears in your own workspace, and after you re-list it, other agencies see a platform-authored "resale" marker on your listing card.

## Prerequisites
- [ ] The TripForge compose stack is running (web on http://localhost:3000)
- [ ] Docker CLI available (the operator vetting steps and the log review use it)

## Prerequisite Verification Commands
```bash
curl -sf http://localhost:3000/api/health    # should print an ok/health JSON
docker compose ps --format '{{.Name}} {{.Status}}' | grep -c running   # should print 2 or more
```
