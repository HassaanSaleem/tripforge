# User Test Card: seed-0027

## Feature (one sentence)
After booking only some of a trip's items, reopening the trip in the
workspace shows a "N of M items booked" count, the realized markup of the
booking, and a "✓ Booked" mark next to each item that was actually booked —
without running a fresh quote.

## Prerequisites
- [ ] The TripForge compose stack is running (web on http://localhost:3000)

## Prerequisite Verification Commands
```bash
curl -sf http://localhost:3000/api/health    # should print an ok/health JSON
docker compose ps --format '{{.Name}} {{.Status}}' | grep -c running   # should print 2 or more
```

## Steps

> All browser steps run against http://localhost:3000 with the Playwright MCP
> browser tools. Save every screenshot into the evidence directory

### Step 1: Create the agency account
**Browser action:** navigate to http://localhost:3000/sign-up, fill "Your name" with "Uma Uattest", fill "Email" with "uat27-agent@example.test", fill "Password" with "uat27-pass-123", fill "Agency name" with "UAT Compass 27", click the "Create account & agency" button
**Expected visible result:** the browser lands on http://localhost:3000/workspace and the header shows "Uma Uattest" and "UAT Compass 27"
**Expected NOT visible:** any error alert
**Screenshot:** save as step-1.png in the evidence directory

### Step 2: Draft the deterministic Paris trip
**Browser action:** on http://localhost:3000/workspace fill "Destination" with "Paris", "Check-in" with "2026-09-01", "Check-out" with "2026-09-04", select "Balanced" in the "Trip style" group, fill "Budget" with "1000", fill "Currency" with "USD", click "Draft itinerary", wait up to 90 seconds for "Compare your options" to appear, then click the "Choose this option" button on the card whose top line reads "Balanced"
**Expected visible result:** the heading "Paris balanced trip" appears, with a "Day 1" section listing exactly 3 items (a transfer, a stay, and an activity)
**Expected NOT visible:** "Could not reach the server"
**Screenshot:** save as step-2.png in the evidence directory

### Step 3: Quote at 22% markup
**Browser action:** in the "Book this trip at your markup" section, clear the "Markup %" field and type "22", click "Quote live prices", wait up to 15 seconds for the review table
**Expected visible result:** a review table with exactly 6 rows, every row's "Markup" column showing "22%"
**Expected NOT visible:** "No items could be held"
**Screenshot:** save as step-3.png in the evidence directory

### Step 4: Book only a subset of the 6 held items
**Browser action:** the review table's 6 rows are, in fixed top-to-bottom order: (1) transfer Shared shuttle Paris Airport → Paris, (2) stay Paris Boutique, (3) activity Paris Old Town Walking Tour, (4) activity Paris River Cruise, (5) activity Paris Old Town Walking Tour, (6) transfer Shared shuttle Paris → Paris Airport — every row's checkbox starts checked. Uncheck rows 3, 4, and 5 only (leave rows 1, 2, and 6 checked), then click "Book selected items", wait up to 10 seconds
**Expected visible result:** "Booking confirmed" and exactly 3 lines containing "supplier ref"
**Expected NOT visible:** "Booking failed"
**Screenshot:** save as step-4.png in the evidence directory

### Step 5: Reopen the trip from the Trips list
**Browser action:** click the "Trips" link in the page header, wait for the "Paris balanced trip" row to appear, click its "Open" button
**Expected visible result:** the text "3 of 6 items booked. Booked at 22% markup." appears near the top of the opened trip, above the "Bookings on this trip" line
**Expected NOT visible:** "Nothing booked yet."
**Screenshot:** save as step-5.png in the evidence directory

### Step 6: Exactly the booked items are marked, no others
**Browser action:** read the full opened-trip page (Day 1, Day 2, and Day 3 sections)
**Expected visible result:** the text "✓ Booked" appears exactly 3 times on the page, next to: the Day 1 transfer row (Shared shuttle Paris Airport → Paris), the Day 1 stay row (Paris Boutique), and the Day 3 transfer row (Shared shuttle Paris → Paris Airport)
**Expected NOT visible:** "✓ Booked" next to either "Paris Old Town Walking Tour" row or the "Paris River Cruise" row
**Screenshot:** save as step-6.png in the evidence directory

### Step 7: Log review
```bash
docker compose logs --no-color | grep -E "ERROR|FATAL|Unhandled" | grep -v "booking_component_itinerary_item_idx" | wc -l
```
**Expected exit code:** 0
**Expected output contains:** "0"
**Expected output does NOT contain:** "Unhandled"
