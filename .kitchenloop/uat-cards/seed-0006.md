# User Test Card: seed-0006

## Feature (one sentence)

A vetted agency can list a finished itinerary on the marketplace with license
terms; another vetted agency can license it and receive a white-label copy with
provenance, with the revenue-share split (license price = platform take +
seller credit) recorded in the database in the same transaction; only
licensees can rate; unvetted agencies are refused on both sides.

## Prerequisites

- [ ] The built app stack is running and reachable at http://localhost:3000 (docker compose: web + postgres + mailpit)
- [ ] Docker is available on the host (used for the operator vetting action and database checks)

## Prerequisite Verification Commands

```bash
curl -s -o /dev/null -w "%{http_code}" http://localhost:3000/api/health   # should print 200
docker compose -p tripforge ps --format '{{.Name}} {{.Status}}' | grep -c healthy   # should print 3
```

## Steps

Every bash step below begins by loading shared variables from /tmp/uat6.env and
ends by saving any new ones, so steps may be run in separate shells but MUST be
run in order.

### Step 1: A brand-new agent signs up and founds the SELLER agency
```bash
RND=$(date +%s)
curl -s -c /tmp/uat6-seller.jar -H "content-type: application/json" -H "origin: http://localhost:3000" \
  -d "{\"email\":\"uat-seller-$RND@example.test\",\"password\":\"correct-horse-battery-staple-1\",\"name\":\"UAT Seller\"}" \
  http://localhost:3000/api/auth/sign-up/email > /tmp/uat6-signup-seller.json
curl -s -b /tmp/uat6-seller.jar -c /tmp/uat6-seller.jar -H "content-type: application/json" -H "origin: http://localhost:3000" \
  -d "{\"name\":\"UAT Atlas DMC\",\"slug\":\"uat-atlas-$RND\"}" \
  http://localhost:3000/api/auth/organization/create > /tmp/uat6-org-seller.json
SELLER_ORG=$(node -e "const j=require('/tmp/uat6-org-seller.json');console.log(j.id??j.organization?.id??'')")
curl -s -b /tmp/uat6-seller.jar -c /tmp/uat6-seller.jar -H "content-type: application/json" -H "origin: http://localhost:3000" \
  -d "{\"organizationId\":\"$SELLER_ORG\"}" http://localhost:3000/api/auth/organization/set-active > /dev/null
echo "SELLER_ORG=$SELLER_ORG" > /tmp/uat6.env
echo "SELLER_SLUG=uat-atlas-$RND" >> /tmp/uat6.env
echo "RND=$RND" >> /tmp/uat6.env
curl -s -b /tmp/uat6-seller.jar http://localhost:3000/api/trpc/workspace.whoami
```
**Expected exit code:** 0
**Expected output contains:** "agencyId"
**Expected output does NOT contain:** "FORBIDDEN"

```bash

  tripforge-verify node packages/db/scripts/vet-agency.mjs "$RESELLER_SLUG" uat-operator
```
**Expected exit code:** 0
**Expected output contains:** "VETTED"
**Expected output does NOT contain:** "FAILED"

### Step 8: The reseller licenses the listing — exact revenue-share split returned
```bash
. /tmp/uat6.env
curl -s -b /tmp/uat6-reseller.jar -H "content-type: application/json" -H "origin: http://localhost:3000" \

  http://localhost:3000/api/trpc/workspace.marketplace.licenseListing > /tmp/uat6-licensed.json

```
**Expected exit code:** 0
**Expected output contains:** "status":"licensed"
**Expected output contains:** "platformTakeMinor":2500
**Expected output contains:** "sellerCreditMinor":22500

### Step 9: The database recorded the split as one conserving ledger row
```bash
. /tmp/uat6.env
docker compose -p tripforge exec -T postgres psql -U tripforge -d tripforge -t -A \
  -c "SELECT price_minor, platform_take_minor, seller_credit_minor, currency FROM revenue_share_ledger WHERE license_id = '$LICENSE_ID'"
```
**Expected exit code:** 0
**Expected output contains:** 25000|2500|22500|USD

### Step 10: The white-label copy belongs to the reseller and carries provenance

. /tmp/uat6.env
