# User Test Card: seed-0030

## Feature (one sentence)
A seller agency can see, on their own marketplace listing card, exactly how many times it has been licensed and the exact total they have earned from it (zero before any license, the exact conserved amount after), and their workspace trip list marks a listed trip with its fee — while another agency never sees those earnings figures for a listing it doesn't own.

## Prerequisites
- [ ] The TripForge compose stack is running (web on http://localhost:3000)
- [ ] Docker CLI available (the operator vetting steps and the log review use it)

## Prerequisite Verification Commands
```bash
curl -sf http://localhost:3000/api/health    # should print an ok/health JSON
docker compose ps --format '{{.Name}} {{.Status}}' | grep -c running   # should print 2 or more
```

## Steps

> All browser steps run against http://localhost:3000 with the Playwright MCP
> browser tools. Save every screenshot into the evidence directory
> `.kitchenloop/uat-runs/seed-0030/`.

### Step 1: Create the SELLER agency account
**Browser action:** navigate to http://localhost:3000/sign-up, fill "Your name" with "Seri Seller", fill "Email" with "uat30-seller@example.test", fill "Password" with "uat30-pass-123", fill "Agency name" with "UAT Atlas 30", click the "Create account & agency" button
**Expected visible result:** the browser lands on http://localhost:3000/workspace and the header shows "Seri Seller" and "UAT Atlas 30"
**Expected NOT visible:** any error alert
**Screenshot:** save as step-1.png in the evidence directory

### Step 2: Draft an itinerary in the workspace
**Browser action:** on http://localhost:3000/workspace fill "Destination" with "Paris", "Check-in" with "2026-09-01", "Check-out" with "2026-09-03", "Adults" with "2", "Children" with "0", select "balanced" for "Trip style", fill "Budget" with "1000", select "hardCap" for "Budget mode", fill "Currency" with "USD", click "Draft itinerary", wait up to 90 seconds
**Expected visible result:** a drafted itinerary appears with day-by-day items and a "Budget summary" table; below it, the "Trips in your workspace" panel lists the new trip with a "USD" badge and NO "Listed" badge
**Expected NOT visible:** any text starting with "Listed ·"
**Screenshot:** save as step-2.png in the evidence directory

### Step 3: The platform operator vets the seller agency
```bash
docker compose exec -T postgres psql -U tripforge -d tripforge -tAc "INSERT INTO agency_vetting (agency_id, vetted_by) SELECT id, 'uat-operator' FROM organization WHERE name = 'UAT Atlas 30' ON CONFLICT (agency_id) DO NOTHING; SELECT count(*) FROM agency_vetting v JOIN organization o ON o.id = v.agency_id WHERE o.name = 'UAT Atlas 30';"
```
**Expected exit code:** 0
**Expected output contains:** "1"
**Expected output does NOT contain:** "ERROR"

### Step 4: List the drafted trip on the marketplace
**Browser action:** click the "Marketplace" link in the page header; in the "List a finished itinerary" form, select the first real option of "Itinerary", fill "Listing title" with "Paris weekender UAT30", fill "License fee (USD)" with "250", fill "License terms" with "White-label permitted; keep attribution lineage.", fill "Revenue share %" with "7.5", click "List it on the marketplace"
**Expected visible result:** "Listed — your trip is live on the marketplace above." AND a listing card titled "Paris weekender UAT30" showing a "Your listing" badge and the text "0 licenses · 0.00 USD earned"
**Expected NOT visible:** "1 license"
**Screenshot:** save as step-4.png in the evidence directory

### Step 5: The workspace trip list shows the Listed mark
**Browser action:** click the "Workspace" link in the page header
**Expected visible result:** the "Paris weekender" trip row (the one just listed) shows a badge reading exactly "Listed · 250.00 USD" next to its "USD" currency badge
**Expected NOT visible:** a trip row with no "Listed ·" badge (every trip drafted in this card is the one that was listed)
**Screenshot:** save as step-5.png in the evidence directory

### Step 6: Create the BUYER agency account
**Browser action:** click "Sign out", then navigate to http://localhost:3000/sign-up, fill "Your name" with "Buri Buyer", fill "Email" with "uat30-buyer@example.test", fill "Password" with "uat30-pass-123", fill "Agency name" with "UAT Nomad 30", click "Create account & agency"
**Expected visible result:** the browser lands on http://localhost:3000/workspace and the header shows "Buri Buyer" and "UAT Nomad 30"
**Expected NOT visible:** any error alert
**Screenshot:** save as step-6.png in the evidence directory

### Step 7: The platform operator vets the buyer agency
```bash
docker compose exec -T postgres psql -U tripforge -d tripforge -tAc "INSERT INTO agency_vetting (agency_id, vetted_by) SELECT id, 'uat-operator' FROM organization WHERE name = 'UAT Nomad 30' ON CONFLICT (agency_id) DO NOTHING; SELECT count(*) FROM agency_vetting v JOIN organization o ON o.id = v.agency_id WHERE o.name = 'UAT Nomad 30';"
```
**Expected exit code:** 0
**Expected output contains:** "1"
**Expected output does NOT contain:** "ERROR"

### Step 8: The buyer sees the seller's card with NO earnings figure, then licenses it
**Browser action:** navigate to http://localhost:3000/marketplace; find the "Paris weekender UAT30" card (seller "UAT Atlas 30")
**Expected visible result:** the card shows NO text containing "licenses" and NO text containing "earned" anywhere on it (earnings are seller-only); the card has a "License this trip" button (no "Your listing" badge)
**Expected NOT visible:** "0 licenses" or "earned" anywhere on this card
**Screenshot:** save as step-8.png in the evidence directory

### Step 9: Complete the license
**Browser action:** click "License this trip" on the "Paris weekender UAT30" card and wait for the receipt
**Expected visible result:** a panel titled "Trip licensed — white-label copy created" showing the rows "License fee 250.00 USD", "Seller credit 225.00 USD", "Platform take 25.00 USD"

**Screenshot:** save as step-9.png in the evidence directory

### Step 10: The seller signs back in and sees the updated earnings
**Browser action:** click "Sign out", navigate to http://localhost:3000/sign-in, fill "Email" with "uat30-seller@example.test", fill "Password" with "uat30-pass-123", click "Sign in", then click the "Marketplace" link in the page header
**Expected visible result:** the "Paris weekender UAT30" card (marked "Your listing") now shows the text "1 license · 225.00 USD earned"
**Expected NOT visible:** "0 licenses"
**Screenshot:** save as step-10.png in the evidence directory

### Step 11: Compose-log review
```bash
docker compose logs --no-color | grep -E "ERROR|FATAL|Unhandled" | grep -v "duplicate key value violates unique constraint" | head -20
```
**Expected exit code:** 0 or 1 (grep finding nothing exits 1 — that is the PASS case)
**Expected output contains:** "" (empty output is the expected result)
**Expected output does NOT contain:** "FATAL"
