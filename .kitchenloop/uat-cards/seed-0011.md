# User Test Card: seed-0011

## Feature (one sentence)
The traveler-facing client view (/view) carries no platform branding anywhere —
including the browser tab title and page metadata — while the platform's own
surfaces keep their platform branding.

## Prerequisites
- [ ] The TripForge stack is running and healthy

## Prerequisite Verification Commands
```bash
curl -s http://localhost:3000/api/health    # prints {"status":"ok","db":"up"}
```

## Steps

### Step 1: Open the client view — traveler content is present
**Browser action:** navigate to http://localhost:3000/view
**Expected visible result:** heading "Your trip" and the text "This is the traveler-facing view"
**Expected NOT visible:** "TripForge", "Trellis"
**Screenshot:** save as step-1.png in the evidence directory

### Step 2: The browser tab title carries no platform branding
**Browser action:** on http://localhost:3000/view, read the page title (the browser
reports it on every navigation; you may also read document.title)
**Expected visible result:** page title is "Your trip"
**Expected NOT visible:** a page title containing "TripForge" or "Trellis"
**Screenshot:** save as step-2.png in the evidence directory

### Step 3: Raw page HTML carries no platform branding (negative — beyond rendered text)
```bash
curl -s http://localhost:3000/view | grep -oiE "tripforge|trellis" | wc -l
```
**Expected exit code:** 0
**Expected output contains (trimmed):** "0"

### Step 4: Platform surfaces still carry the platform brand (separation, not deletion)
**Browser action:** navigate to http://localhost:3000/
**Expected visible result:** heading "TripForge"; page title "TripForge"
**Expected NOT visible:** an error page
**Screenshot:** save as step-4.png in the evidence directory

### Step 5: Workspace surface intact
**Browser action:** navigate to http://localhost:3000/workspace
**Expected visible result:** heading "Agency workspace" and an agency-membership sign-in prompt
**Expected NOT visible:** an error page
**Screenshot:** save as step-5.png in the evidence directory

## Artifacts
- `evidence.md` plus step-1/2/4/5 screenshots in the evidence directory

## Constraints
- MAX_DURATION: 120
